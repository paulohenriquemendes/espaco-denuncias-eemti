# Espaço de Denúncias — EEMTI Dalva Queiroz de Carvalho

Canal sigiloso de combate ao racismo e ao bullying.

**Site publicado via GitHub Pages.** Projeto vinculado ao programa Selo Sustentável da Seduc (Ceará).

## Formulários
- Denúncia de Racismo: https://docs.google.com/forms/d/e/1FAIpQLSeIWJcpQjpZmB7pggJbDv9XRCqDuoxP-m0_NsIWLdpL04LBvA/viewform
- Denúncia de Bullying: https://docs.google.com/forms/d/e/1FAIpQLSeCHXJImqyAoVvvWNtaL1qZO-GqzXhaqVeR5K97FmmxAz22tg/viewform

## Como editar
O site inteiro está no arquivo `index.html` (página única, sem dependências além das fontes do Google). Depois de alterar, faça commit na branch `main` que o GitHub Pages publica automaticamente.
